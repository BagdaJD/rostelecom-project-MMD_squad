# Формат экспорта

Требование кейса: выгрузка CSV/CRM **из любого модуля** и DOCX для коммерческого предложения.
`POST /api/v1/exports/csv` принимает `module=companies|investments`, `mode=general|crm`
и объект `filters`. Неизвестный фильтр или некорректное значение дают HTTP 422.
Основной DOCX: `GET /api/v1/calculator/estimates/{id}/proposal`;
`POST /api/v1/exports/proposal` сохранён для прежнего `/deals/estimate`.

## CSV (режим `general`)

| Свойство | Значение |
|---|---|
| Кодировка | UTF-8 **с BOM** (иначе Excel портит кириллицу) |
| Разделитель | запятая |
| Кавычки | по RFC 4180 |
| Даты | ISO 8601 (`YYYY-MM-DD`); если известен только год — `YYYY` |
| Пустое значение | пустая строка, **не** `0` и не `null` |

Модуль `companies`:

| Колонка выгрузки | Поле API | Комментарий |
|---|---|---|
| Идентификатор | `id` | внутренний id, нужен для обратной связи в CRM |
| Название | `name` | как в источнике |
| ИНН | `inn` | пусто, если источник не дал ИНН |
| Статус клиента | `client_status` | действующий / потенциальный / не определён |
| Отрасль | `industry` | бизнес-отрасль (ТЭК, Торговля, АПК…), не ОКВЭД |
| Регион | `region` | наименование региона |
| Код региона | `region_code` | устойчивый общий код |
| Выручка, млн руб | `revenue_latest` | последний доступный год |
| Год выручки | `revenue_year` | обязателен: выручка без года бессмысленна |
| Динамика выручки, % | `revenue_yoy` | пусто при ряде меньше двух лет |
| Источник и дата | — | ссылка на первичную запись и дату получения |
| Ссылка на источник | `source_url` | пусто для локальной книги; файл/лист/строка — в «Источник и дата» |
| Синтетическая компания | `is_synthetic` | `True` / `False` |
| Синтетическая финансовая опора | `revenue_is_synthetic` | природа финансов отдельно от самой компании |

Модуль `investments`: идентификатор, название проекта, ИНН инициатора (если известен),
инициатор, стадия и основание стадии, регион и код региона, муниципалитет, отрасль,
начало, плановый ввод, бюджет **в рублях**, источник и дата, ссылка.
Отдельная колонка «Синтетический проект» содержит `is_synthetic`.
Годы из Excel не разворачиваются в фиктивные точные даты. Стадия `unknown` означает,
что описание не позволяет даже предварительно определить стадию.

Фильтры компаний: `region_id`, `industry_id`, `industry_group`, `client_status`,
`municipality`, `q`, `min_revenue`, `min_growth`, `report_year`.
Фильтры проектов: `region_id`, `industry_id`, `stage`, `initiator_company_id`, `municipality`, `q`.
Фильтрация использует те же сервисы, что и списки API, до применения лимита.

## CRM-режим (`mode=crm`)

Колонки фиксированы и стабильны по порядку: `externalId, name, inn, industry, region, phone, website`.
Для проектов `name` — название проекта, `inn` — ИНН его инициатора. Телефон и сайт
остаются пустыми: в источнике их нет. Идентификаторы трактуются в контексте выбранного модуля.
Строки, начинающиеся с формулы Excel, экранируются при выгрузке.

**Открытый вопрос куратору:** целевая CRM и её поля не названы в кейсе. Пока используется
универсальный набор; после уточнения меняется только `CRM_COLUMNS` в
`backend/modules/exports/service.py` и эта таблица — контракт UI при этом не меняется.

## DOCX коммерческого предложения

Состав документа (генерируется `python-docx`, файл остаётся редактируемым):

1. Шапка и дата расчёта в UTC, версия модели оценки.
2. Параметры проекта ровно в том виде, в каком их ввёл пользователь.
3. Вилка: минимум / оптимум / максимум, метод расчёта, качество данных, период ретро-цен.
4. Аналоги с коэффициентом сходства и указанием природы цены (`contract` / `estimate` / `synthetic`).
5. Поправки: региональный коэффициент, срочность, уникальные решения.
6. Обязательный блок «Ограничения»: оценка требует проверки специалистом.

Общий CSV и прежний DOCX пишут `export.csv`, `export.proposal`, `export.download`
в `audit_log`. Выгрузки требуют подтверждённой MFA-сессии. Оба калькулятора проверяют
владельца расчёта; admin имеет доступ ко всем. Новый калькулятор пишет
`calculator.estimate`, `calculator.approve`, `calculator.csv`, `calculator.proposal`.
Внутренний DOCX разрешён аналитику для своего расчёта и администратору.
У прежнего POST `/exports/proposal` ответ содержит `download_url` вместо `file_ref`.
Подробности: [auth-and-access.md](auth-and-access.md).

## Большие выгрузки

Синхронный CSV возвращает до 5000 строк. Для текущих 819 компаний и 63 проектов
это полная выборка. Фоновая генерация, job id и защищённое скачивание больших выгрузок
остаются задачей следующего этапа; сейчас такого API нет.
