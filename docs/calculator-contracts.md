# Реальные контракты из ЕИС для калькулятора сделок

ЕИС (zakupki.gov.ru) не разрешает автоматический сбор данных, поэтому контракты вносятся
вручную: 30–50 строк — примерно час работы одного человека. Каждый контракт сразу становится
аналогом в калькуляторе, а ставки проигравших участников — обучающими примерами для модели
шанса выиграть.

## Что искать

На zakupki.gov.ru → «Контракты и договоры» (44-ФЗ и 223-ФЗ):

- запросы: «диспетчеризация», «система диспетчеризации инженерных систем», «АСКУЭ»,
  «узел учёта тепловой энергии с передачей данных», «мониторинг инженерных систем»;
- регион: Ростовская область, при нехватке — весь ЮФО;
- период: 2023–2026, статус «исполнен» или «исполнение».

**Брать:** установку (поставка + монтаж + наладка) диспетчеризации или учёта в здании, где
понятно, что за объект.

**Не брать:** только обслуживание, капремонт целого здания, диспетчеризацию лифтов, пожарную
сигнализацию, видеонаблюдение, расторгнутые контракты, контракты сразу на много зданий.

## Как заполнить

1. Скопируйте `data/contracts/contracts_template.csv` в `data/contracts/contracts.csv`
   (Excel: «Сохранить как» → CSV UTF-8, разделитель «;»).
2. Одна строка — один контракт. Строку-пример с номером «ПРИМЕР-0001» удалите.

| Колонка | Откуда взять | Обязательно |
|---|---|---|
| Номер в ЕИС | реестровый номер контракта | да |
| Ссылка | адрес карточки | желательно |
| Предмет контракта | из карточки | да |
| Заказчик, ИНН заказчика | из карточки | желательно |
| Регион | «Ростовская обл.», «Юг», «Центр», «Северо-Запад», «Урал», «Сибирь» | да |
| Город | из адреса заказчика | нет |
| Тип объекта | торговый объект, склад, офис, производство, АПК, МКД, соцобъект (школа, больница), отдых и спорт; пусто — угадывается по предмету | желательно |
| Площадь, м² | из ТЗ или сметы; если нет — по паспорту здания | **да** |
| Системы | через запятую: Электроснабжение, Отопление, Водоснабжение, Водоотведение, Вентиляция, Кондиционирование, Газоснабжение | желательно |
| Уровень | базовый (только мониторинг) / продвинутый (+управление) / экспертный (+авторегулирование) | желательно |
| Закон | 44 или 223 | желательно |
| Начальная цена, руб | НМЦК из извещения | желательно |
| Цена контракта, руб | итоговая цена | **да** |
| Ставки других участников, руб | из протокола подведения итогов, через запятую | очень желательно |
| Дата контракта | ГГГГ-ММ-ДД | желательно |

## Ограничение

Себестоимость контракта оценивается по площади и каталогу кейса тем же расчётом, что и в
калькуляторе (`cost_basis = estimated_by_area`), — реальной себестоимости исполнителя в ЕИС
нет. Поэтому наценка контракта — оценка, а не факт; если есть смета, точнее указать состав.
