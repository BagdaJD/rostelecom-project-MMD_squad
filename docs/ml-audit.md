# Аудит перед реализацией (24.10.2026)

Исторический аудит этапа 1. Актуальные исправления и реальные проверки:
[отчёт этапа 2](ml-stage2-report.md).

Рабочее дерево изначально чистое. Изучены README, ingestion, ML, модели, схемы,
API, сервисы radar/investments, тесты, документация и три материала организатора.
Постановка из DOCX/PDF используется как контекст; область работ задана пользователем.

Подтверждённые проблемы исходного кода:

- Для 12-значного ИНН проверяются цифры 10/11 вместо 11/12 и неверные веса.
- ОГРН проверяется только по длине; импорт выбирает компанию по имени без территории
  и использует её даже при другом валидном ИНН. Имя не является ключом объединения.
- `fetched_at` участвует в hash исходной компании: повторный запуск меняет provenance.
  CompanyMatch добавляется при каждом импорте; raw_payload содержит datetime, который
  стандартный JSON-сериализатор SQLAlchemy не принимает.
- NLP ищет подстроки (`ср`, `пн`, `информационн`), теряет регистр исходной цитаты,
  присваивает правилам псевдовероятности и не различает explicit/inferred.
- Радар суммирует все годы выручки и считает строки метрик вместо компаний;
  сравнивает в том числе одинаковые годы; неизвестные присутствие и рост становятся нулями.
- Нет Excel/FNS-импорта, семантического NLP, разметки, company scoring и CLI для них.
- В каркасе есть Alembic env, но нет ни одной ревизии с созданием исходных таблиц.

Фактура: лист МОД1_Таб1 — 759 строк; МОД\"_Таб1 — 63 строки. МОД3_* исключены.
ИНН/ОГРН хранятся строками, включая ведущие нули. Нет выручки и ИНН инициаторов.
У 601 компании нет численности; все 759 записей относятся к Ростовской области.
В контактах/территориальных полях нет самостоятельного значения 136: глобальная
замена запрещена; очистка такой заглушки возможна только через явную конфигурацию.
В Excel есть персональные сведения ИП: публичные отчёты должны содержать агрегаты,
а нормализованные записи и шаблоны разметки хранятся локально в игнорируемых artifacts.

На машине Python 3.12.0. В исходном интерпретаторе нет SQLAlchemy, установлен
несовместимый старый пакет docx. Проверки выполняются в отдельной .venv проекта.
Полного XML/ZIP ФНС, экспертных меток и корпоративных исходов продаж не предоставлено.
